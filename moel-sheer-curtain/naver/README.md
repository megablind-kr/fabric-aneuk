# MOEL 상세페이지 — 네이버 시안

- 업데이트: 2026-11-17
- 페이지: [index.html](index.html)

## 작업 설명

MOEL(모엘) 시어(쉬폰) 커튼의 네이버 스마트스토어 상세페이지입니다. 원단 6종(컬러 옵션 10개)을 상품 하나로 묶어 소개합니다.

- **디자인:** 심플·모던·고급 톤, 고딕 단일 서체, 가로 860px 기준
- **제작 방식:** HTML/CSS로 디자인 → 섹션별 이미지로 렌더링해 스마트스토어에 업로드
- **구성:** 상단 공지 → 메인 비주얼 → 브랜드 신뢰 → 주문 방법 → 컬렉션 소개 → 빛 비침 비교 → 화면 색상 안내 → 공통 특징 → 원단별 상세(6종) → 주름 가이드 → 실측 가이드 → 사이즈 계산 → 기본 구성품 → 추가 상품 → 설치 방법 → 주문 제작 안내 → 세탁 방법 → 안내사항 → CS
- **주문 방식(네이버):** 가로 실측 cm를 수량으로, 세로 기장은 직접 입력
- **움직이는 부분:** 메인 타이틀(MOEL)과 누적 시공 건수는 페이지에서는 애니메이션으로 보이고, 섹션 이미지에서는 정지 화면입니다
